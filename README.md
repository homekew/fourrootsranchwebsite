# Four Roots Ranch Website Prototype

This repo contains a static homepage prototype for Four Roots Ranch Animal Sanctuary.

The prototype keeps the llama image directly below the navigation and uses a warmer editorial ranch-journal layout instead of stat bands, eyebrow headers, or generic landing-page sections.

## Files

- `index.html`
- `styles.css`

## How to preview

Open `index.html` in a browser, or enable GitHub Pages for this repository.

## Notes

The live site is still hosted on Squarespace, so this prototype does not change the public website.
